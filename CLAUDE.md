# ck3chronicle repository guidance

Read and follow `AGENTS.md` before doing any work. It is the normative project
instruction file; `docs/CURRENT_HANDOFF.md` is the current restart context and
`docs/WORKSPACE_ROUTING.md` is the ownership map.

This standalone Git root is the only ck3chronicle implementation repository.
Do not write ck3chronicle source into `ck3raven`, `.ck3raven/wip`, or an old
WIP learner tree. The learner and catalog tools are already owned here under
`tools/template_learning/`.

Unknown and low-confidence template assignments are legitimate review queues.
Complete occurrence accounting is required; 100% L1/L2 attribution is not.
