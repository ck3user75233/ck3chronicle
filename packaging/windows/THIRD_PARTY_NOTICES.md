The bundle contains the following identified components. Their included license
and notice files are retained with the application.

| Component | Version | Included notice |
|---|---|---|
| ck3chronicle | 0.0.3 | Application wheel metadata records its license field as TBD. |
| CPython | 3.12.14, Windows x64 | `runtime/LICENSE.txt` contains the supplied Python licenses and additional notices. |
| chardet | 7.6.0 | Wheel metadata and the `licenses` directory under `runtime/Lib/site-packages/chardet-7.6.0.dist-info/`. |

`release-manifest.json` identifies the bundled runtime, tool, application and
resource files by SHA-256. Windows PowerShell and .NET Framework are Windows
prerequisites supplied by the operating environment.
